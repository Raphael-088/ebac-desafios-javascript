🚀 Desafios JavaScript - EBAC
Projeto desenvolvido para resolução dos exercícios do módulo de JavaScript da EBAC.

📋 Desafios
1️⃣ Cálculo do MDC (Máximo Divisor Comum)
Desenvolver uma função capaz de calcular o MDC entre dois números utilizando o algoritmo de Euclides.

Arquivo:

desafio1-mdc.js
2️⃣ Índice do maior e menor valor
Dado um array numérico sem valores repetidos, identificar o índice do maior e do menor valor.

Arquivo:

desafio2-array.js
3️⃣ Soma dos múltiplos
Criar uma função que retorne a soma de todos os múltiplos de 5 ou 7 abaixo de 1000.

Arquivo:

desafio3-multiplos.js

▶▶️ Como executar
Clone o repositório:

git clone https://github.com/Raphael-088/ebac-desafios-javascript.git
Acesse a pasta do projeto:

cd ebac-desafios-javascript
Execute os exercícios:

Desafio 1
node desafio1-mdc.js
Desafio 2
node desafio2-array.js
Desafio 3
node desafio3-multiplos.js
